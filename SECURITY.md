# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a vulnerability

If you find a security vulnerability in KillToken (for example, permission
bypasses or item duplication), please **do not open a public issue**.

Report it privately to the maintainer at
[ro161012](https://github.com/ro161012) (via GitHub email or a private
discussion). You should receive an acknowledgement within a few days and a
fix will be prioritised in the next release.
